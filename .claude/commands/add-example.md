---
description: 添加代码示例到对应的 package
---

帮我创建一个新的代码示例。

请按以下步骤操作：

1. 询问示例的类型：
   - browser（浏览器环境）
   - node（Node 环境）
   - react-source（React 源码实现）
   - vue-source（Vue 源码实现）
   - ui-react（React UI 组件）
   - ui-vue（Vue UI 组件）

2. 询问示例的名称和功能描述

3. 在对应的 `packages/examples-*` 或 `packages/ui-*` 目录下创建文件

4. 使用合适的模板：
   - 包含中文注释
   - 遵循项目代码规范
   - 确保示例可独立运行
   - 添加必要的类型定义
