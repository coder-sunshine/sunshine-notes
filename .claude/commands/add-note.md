---
description: 添加新的技术笔记
---

帮我创建一个新的技术笔记。

请按以下步骤操作：

1. 询问我笔记的类型（frontend 或 backend）
2. 询问具体的技术分类（如 react、vue、typescript、nest 等）
3. 询问笔记的主题和文件名
4. 在对应的 `apps/docs/src/content/docs/` 目录下创建 MDX 文件
5. 使用标准的笔记模板，包含：
   - 标题和描述
   - 目录结构
   - 代码示例占位符
   - 参考链接部分

注意：

- 文件名使用 kebab-case
- 代码注释使用中文
- 确保代码示例可独立运行
