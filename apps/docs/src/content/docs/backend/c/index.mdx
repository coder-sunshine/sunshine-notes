## 怎么用这套文档

每章都按下面的节奏学：

1. 先看“本章目标”，知道这章解决什么问题。
2. 再看“核心知识”，把概念和语法模板记下来。
3. 接着抄写“示例代码”，不要只看，最好自己敲一遍。
4. 然后做“手写题”，先在纸上写，再上机运行。
5. 最后对照“自测清单”，检查有没有真正掌握。

## 建议的学习方式

- 每次学习控制在 30 到 60 分钟。
- 每章至少做 5 道手写题。
- 遇到不会的题，先画出变量变化过程。
- 不要一开始追求写得特别高级，先把基础逻辑写对。
- 代码运行后，自己解释每一行做了什么，这一步很重要。

## 你现在最应该关注的主线

- 第 2 章：会输入、会计算、会输出。
- 第 3 章：会判断条件，走不同分支。
- 第 4 章：会重复执行，解决成批计算。
- 第 5 章：会处理一组数据。
- 第 6 章：会把程序拆成函数。
- 第 7 章：开始真正理解地址、数组、字符串和函数之间的联系。

## 学完一章以后你可以这样复盘

- 我能不能不看资料写出最基本模板？
- 我能不能说清楚每个变量的作用？
- 我能不能自己举一个类似例子？
- 我能不能做出至少 3 道题？
